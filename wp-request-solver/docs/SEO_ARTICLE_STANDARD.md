## 1. סוגי המאמרים

### 1.1 מאמר SEO עצמאי (פנימי באתר)
- אורך לפי כוונת חיפוש (1,200-2,000 מילים בדרך כלל)
- 3-5 קישורים פנימיים לקטגוריות/דפים באתר
- אזכור מותג 1-2 פעמים בגוף, **0 בפתיח**, **0 ב-FAQ**
- מתפרסם בבלוג של האתר עצמו

### 1.2 מאמר אשכול תוכן (Pillar + Supporting)
- **Pillar**: 2,000-3,000 מילים, נושא רחב ומקיף, 5-8 קישורים פנימיים
- **Supporting**: 600 מילים כל אחד, נושא מצומצם, 2-3 קישורים (כולל ל-Pillar)
- כל Supporting מקשר ל-Pillar באמצע המאמר
- ה-Pillar מציין שהנושאים קיימים, אבל לא מקשר אליהם בגוף

### 1.3 מאמר Backlink (קישור חיצוני)
- מתפרסם באתר חיצוני, **לא** באתר הלקוח
- **קישור 1 בלבד** לאתר היעד
- **0 אזכורי מותג ישירים** (אין "אנחנו", אין שם חברה)
- anchor text טבעי ורלוונטי
- תוכן אינפורמטיבי טהור, לא שיווקי
- אורך 1,200-1,500 מילים

## 2. תהליך העבודה

### 2.1 לפני הכתיבה - בדיקה ראשונה
1. סריקת האתר (אם זמין דרך URL)
2. הבנת העסק, הקהל והקטגוריות הקיימות
3. בחירת מילת מפתח ראשית + גיוון סמנטי
4. תכנון מבנה המאמר (כותרות H2)
5. תכנון 3-5 קישורים פנימיים מהאתר
6. תכנון איפה יופיעו 1-2 אזכורי המותג
7. תכנון איפה צריך טבלה (3+ שורות), בולטים (4+ פריטים), מספור (שלבים בסדר)

### 2.2 אישור לקוח (אופציונלי)
- הצגת תוכנית מסודרת לפני כתיבה
- אישור הנושא, הזווית, וההגשה
- במצבים שדורשים מהירות - דילוג על שלב התוכנית

### 2.3 אחרי הכתיבה - בדיקת צ'קליסט מלאה
- 18 נקודות, כולן חייבות להיות ✅
- לא 95%, לא "כמעט עומד"
- אם משהו לא ירוק - תיקון לפני הצגה ללקוח

## 3. מבנה הקבוע של כל מאמר

### 3.1 H1 - הכותרת הראשית
- **בנפרד מ-HTML** (להעתקה לשדה כותרת WordPress)
- **ללא סוגריים**
- מכילה את מילת המפתח הראשית
- 50-80 תווים בדרך כלל
- מסופקת בבלוק קוד נפרד

### 3.2 Meta Title
- 50-60 תווים בדיוק
- מכיל את מילת המפתח
- ללא סוגריים
- כולל שם המותג בסוף עם דאש או pipe (` - שם המותג` או ` | שם המותג`)

### 3.3 Meta Description
- 150-160 תווים בדיוק
- מתחיל בשאלה, כאב או הצגת ערך
- כולל מילת המפתח
- מסיים ב-CTA או הבטחת ערך

### 3.4 Slug
- **בעברית בלבד**, מקפים בין מילים
- 3-5 מילים מקסימום
- רלוונטי למילת המפתח
- ללא ה' הידיעה מיותרת
- ללא מילות קישור (של, את, על, ב-, ל-)
- **חריגים מותרים באנגלית**: about / about-us / blog בלבד

### 3.5 פתיח (3 פסקאות)
- **פסקה 1**: סצנה / כאב / צורך אמיתי - **לא** הגדרה יבשה
- **פסקה 2**: הקשר רחב יותר של הבעיה
- **פסקה 3**: הצגת מה המאמר יענה
- **ללא אזכור מותג בפתיח** - אף פעם

### 3.6 גוף המאמר
- 5-8 כותרות H2
- כל כותרת ללא סוגריים
- היררכיה ברורה (H2 ולעיתים H3)
- פסקאות באורך 2-5 שורות

### 3.7 סיכום
- 1-2 פסקאות
- מסכם את המסרים העיקריים
- **כאן יכול להופיע אזכור מותג שני** (CTA טבעי)

### 3.8 FAQ
- כותרת: **"שאלות נפוצות"** (לא "(FAQ)" ולא בסוגריים)
- 5-6 שאלות בדיוק
- שאלה ב-Bold + תשובה בשורה הבאה
- **לא חוזר על תוכן הגוף** - שאלות מרחיבות
- **0 אזכורי מותג ב-FAQ**

## 5. כללי פורמט קשיחים

### 5.1 כותרות - חוקי ברזל
- **כל הכותרות (H1/H2/H3) ללא סוגריים**
- כולל "שאלות נפוצות" (לא "שאלות נפוצות (FAQ)")
- כולל כותרות של סקציות פנימיות

### 5.2 בולטים
- **רק מ-4 פריטים שווי-ערך ומעלה**
- 1-3 פריטים = פרוזה זורמת עם **bold**
- כל בולט באורך מינימום 1-2 משפטים
- אבחון נוקשה: לעצור, לספור, להחליט

### 5.3 מספור
- **רק לשלבים בסדר מוגדר** (זמן, לוגיקה, היררכיה)
- לא במקום בולטים סתם
- כל פריט מתחיל ב-Bold עם שם השלב

### 5.4 טבלאות
- **רק מ-3 שורות נתונים ומעלה**
- מתאים להשוואות, מפת החלטה, חישוב כמויות
- כותרות עמודות ב-`thead`, נתונים ב-`tbody`

### 5.5 Bold
- בחסכנות
- להדגשת מושגים מרכזיים
- לא להדגשה כללית של פסקה שלמה

### 5.6 מקפים
- **מקף קצר רגיל בלבד** ( - )
- **אסור** מקף ארוך ( — )

## 7. מילות מפתח

### 7.1 חוקים
- מילת מפתח ראשית 3-5 חזרות לכל 1,000 מילים
- **גיוון סמנטי חובה** - ללא חזרה רצופה של אותה מילה
- מילת המפתח חייבת להופיע ב:
  - H1
  - פסקה ראשונה
  - Meta Title
  - Meta Description
  - לפחות 2 כותרות H2

### 7.2 דוגמה לגיוון סמנטי
- מילת מפתח: "החזר מס לשכירים"
- גיוון אפשרי: החזר מס / זכויות מס / החזר ממס הכנסה / זיכוי מס

## 8. קישורים פנימיים

### 8.1 כמות לפי סוג מאמר
- **מאמר פנימי**: 3-5 קישורים
- **Pillar**: 5-8 קישורים
- **Supporting**: 2-3 קישורים (כולל ל-Pillar)
- **Backlink**: 1 קישור בלבד

### 8.2 פורמט HTML
```html
<a href="URL_מהאתר">טקסט עוגן רלוונטי</a>
```
- משולב טבעי בתוך משפט
- לא רשימת קישורים
- טקסט עוגן רלוונטי, לא "לחץ כאן"

### 8.3 חיזוק ביטוי בדף הבית (אם הלקוח מבקש)
- כל הקישורים יובילו לדף הבית
- anchor text יכיל את הביטוי בווריאציות שונות

## 13. אופן ההגשה

### 13.1 מבנה התשובה
1. **כותרת H1** - בנפרד, בלוק קוד להעתקה
2. **Meta Title** - בנפרד, בלוק קוד
3. **Meta Description** - בנפרד, בלוק קוד
4. **Slug** - בנפרד, בלוק קוד
5. **גוף המאמר ב-HTML** - בלוק קוד אחד גדול

### 13.2 דרישות פורמט HTML
- פסקאות ב-`<p>`
- כותרות ב-`<h2>` ו-`<h3>` בלבד (לא `<h1>` כי זה בכותרת הפוסט)
- בולטים ב-`<ul><li>`
- מספור ב-`<ol><li>`
- טבלאות ב-`<table><thead><tbody>`
- bold ב-`<strong>`
- קישורים ב-`<a href="">`

### 13.3 מה לא נכלל ב-HTML
- אין `<h1>` בגוף (זה בכותרת הפוסט)
- אין `<html>`, `<body>`, `<head>`
- רק תוכן

## 16. עברית תקנית

### 16.1 חוקי יסוד
- **כתיבה בעברית תקנית בלבד**
- מילים לועזיות מתורגמות לעברית כשיש מקבילה תקנית
- מונחים מקצועיים שאין להם תרגום נשארים באנגלית, אבל בכמות מינימלית
- שפה נגישה אבל מקצועית

### 16.2 ניקוד וסימני פיסוק
- **גרשיים כפולים בעברית**: " ולא "
- **גרש בודד**: ' (לא אפוסטרוף לטיני)
- **שלוש נקודות**: ... (שלוש נקודות רגילות)
- **מקף קצר רגיל**: - בלבד
- **נקודה בסוף משפט**: תמיד

### 16.3 התאמת מין ומספר
- שם עצם זכר עם פועל זכר, נקבה עם נקבה
- יחיד עם יחיד, רבים עם רבים
- "שכירים מקבלים" (לא "שכירים מקבל")
- "נשים בוחרות" (לא "נשים בוחר")

### 16.4 שגיאות נפוצות שאסורות

| שגוי | תקני |
|---|---|
| "אני יעשה" | "אני אעשה" |

```python
def generate_article_image(
    article_title: str,
    article_topic: str,
    image_style: str = "photographic",
    aspect_ratio: str = "1792x1024"
):
    """
    יוצר תמונה למאמר באמצעות DALL-E 3
    
    Parameters:
    - article_title: כותרת המאמר
    - article_topic: נושא קצר של המאמר
    - image_style: סגנון התמונה (photographic, illustration, minimalist)
    - aspect_ratio: יחס התמונה (1792x1024 לקאבר, 1024x1024 לרשתות)
    """
    
    prompt = build_image_prompt(article_title, article_topic, image_style)
    
    response = client.images.generate(
        model="dall-e-3",
        prompt=prompt,
        size=aspect_ratio,
        quality="hd",
        n=1
    )
    
    image_url = response.data[0].url
    return image_url
```

#### 19.4.2 הורדה ושמירה של תמונה
```python
import requests
from pathlib import Path

def download_image(image_url: str, slug: str) -> str:
    """
    מוריד תמונה ושומר אותה לוקאלית
    """
    
    response = requests.get(image_url, timeout=30)
    response.raise_for_status()
    
    output_dir = Path("article_images")
    output_dir.mkdir(exist_ok=True)
    
    filename = f"{slug}.png"
    filepath = output_dir / filename
    
    with open(filepath, "wb") as f:
        f.write(response.content)
    
    return str(filepath)
```
